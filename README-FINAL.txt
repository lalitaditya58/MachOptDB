MachOptDB - Final Website Package

This package contains the latest MachOpt frontend pages and assets.

The working local project also contains the Node.js/MySQL backend (server.js), .env, package.json, package-lock.json and node_modules that were configured during the project.

Run the backend from the project folder with:
  node server.js

Then open:
  http://localhost:3000/index.html

Important:
- Keep your existing .env file private; do not publish your MySQL password.
- This ZIP intentionally does not include node_modules or .env.
